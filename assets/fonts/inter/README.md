# Inter fonts

Bundled, unmodified Inter Regular (400), Medium (500), SemiBold (600) and Bold (700).
These are the same font files previously delivered by the application dependency,
now owned as local assets so removing a component library cannot change typography.

Upstream: https://github.com/rsms/inter
License: SIL Open Font License 1.1, included in OFL.txt and the application license registry.
CJK text uses platform font fallback. No fonts are fetched at runtime.
